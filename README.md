# CodeBox2GO

A modern React app for creating beautiful, customizable code snippets that are ready to use in videos, tutorials, thumbnails, presentations, and social posts.

CodeBox2GO lets you style your code previews visually, adjust the layout, and export high-quality images without manually designing code blocks from scratch.

## Features

* Syntax highlighting
* Fully customizable code boxes
* Edit the header and code content
* Export as PNG with transparent background

## Use Case

CodeBox2GO is mainly built for coding content creators who need good-looking code snippets for:

* YouTube videos
* Course lessons
* Thumbnails
* Slides
* Social media posts
* Documentation visuals

## Tech Stack

* React
* JavaScript
* CSS
* Vite
